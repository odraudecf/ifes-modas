# Front-end — Ifes Modas

React 19 + Vite 8. Veja o [README principal](../README.md) para rodar o projeto completo.

```bash
cp .env.example .env.local   # ajuste VITE_API_URL
npm install
npm run dev     # http://localhost:5173
npm run lint
npm run build   # gera dist/ (publicado como site estático no Render)
```
